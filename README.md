# Auto Gold Steal (Meteor Client Addon - 1.21.11)

## Cach 1: Build bang GitHub (Khong can cai IntelliJ hay Java tren may)
1. Tao mot repository moi tren GitHub.
2. Tai toan bo cac file trong thu muc nay len repository do.
3. Vao tab **Actions** tren GitHub -> chon **Build Addon JAR** -> bam **Run workflow**.
4. Doi khoang 1-2 phut, tai file `auto-gold-steal-jar` o muc **Artifacts**, giai nen lay file `.jar` va bo vao thu muc `mods` cua Minecraft.

## Cach 2: Build truc tiep tren may bang IntelliJ IDEA / Gradle
1. Mo thu muc nay bang IntelliJ IDEA (hoac chay lenh `gradle build` neu da cai Gradle & JDK 21).
2. Lay file `auto-gold-steal-1.0.0.jar` trong thu muc `build/libs/` va copy vao thu muc `mods`.
